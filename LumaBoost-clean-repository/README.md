# LumaBoost (Fabric client mod)

Adds customizable extra keybindings. No custom network packets are registered.

## Access
In Music & Sound Options, hold **Option (⌥)** (either side on Mac) to reveal a small button near the lower right; click while holding Option to open the keybindings editor.

## Toggle
Use the **Switch ON/OFF** button in the editor, press your chosen keys together, then release them to save the combination. Press that combination again to toggle additional bindings on/off. Existing config is read from `config/mbkeys.json`.

## Build
This source archive has **not** been compiled or runtime-tested. Check the Minecraft / Fabric / Java versions in `gradle.properties` and `fabric.mod.json` for consistency before building.
